# Dohari

Official digital identity and city portal for Dohrighat, Uttar Pradesh.

## Features

- Ultra-premium cinematic design
- Scroll-based animated background
- Simplified navigation
- Explore local landmarks, education, and more
- Glassmorphism UI
- Smooth animations

## Tech Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- GSAP
- Lenis

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Note

The animated background frames (public/images/bg-frames) are not included in this repository due to size constraints. You can add them locally if needed.
